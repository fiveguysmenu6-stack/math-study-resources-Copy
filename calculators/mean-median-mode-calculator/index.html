The method behind it

Mean = sum ÷ count. Median = the middle value of the sorted data (the average of the two middle values when the count is even). Mode = the most frequent value; a set can have one, several or no mode. Range = largest − smallest. An outlier is a value more than 1.5 × IQR below Q1 or above Q3.

Worked example

Worked example: 3, 7, 7, 9, 10, 12, 12, 12, 40. The sum is 112 and there are 9 values, so the mean is 12.44. The middle (5th) value is 10, so the median is 10. 12 appears three times, so the mode is 12. The 40 is an outlier, which pulls the mean above the median.

Frequently asked questions

When should I use the median instead of the mean?

Use the median when the data is skewed or has outliers, such as house prices or incomes, because it is not pulled by extreme values.

What if there is no mode?

If every value appears the same number of times there is no mode. The calculator says so.

How is the median found with an even number of values?

Average the two middle values after sorting.
