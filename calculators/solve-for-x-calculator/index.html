Solve for x Calculator

Type an equation with one unknown, such as 5x − 4 = 2x + 11. A balance scale, the exact steps and a graph of both sides show where the solution comes from, and answers stay as exact fractions. You can also test whether a number is a solution.

Runs entirely in your browser. Nothing you enter leaves your device.

How to use the solve for x calculator

  1. Type an equation, using ^ for powers and / for fractions.
  2. Press Solve. Read the steps, then check the graph where the two sides cross.
  3. Use Is a solution? to test a value by substituting it.
  4. Tap an example chip for a linear, fractional or quadratic case.

The method behind it

To solve a linear equation, do the same operation to both sides until x is alone: collect x terms on one side, constants on the other, then divide by the coefficient. Equations containing x² are rearranged to ax² + bx + c = 0 and solved by factoring or the quadratic formula. Always substitute the answer back to check.

Worked example

Worked example: 5x − 4 = 2x + 11. Subtract 2x from both sides: 3x − 4 = 11. Add 4: 3x = 15. Divide by 3: x = 5. Check: 5(5) − 4 = 21 and 2(5) + 11 = 21.

Frequently asked questions

What if the equation has no solution?

Some equations simplify to a false statement such as 3 = 5, meaning no value of x works. Others simplify to a true one, such as 4 = 4, meaning every x works.

Can it solve equations with fractions?

Yes, and the answer stays an exact fraction instead of a rounded decimal.

How do I solve a quadratic equation?

Type it in the same box, or use the dedicated quadratic equation calculator for the discriminant and vertex.
