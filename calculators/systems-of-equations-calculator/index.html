Systems of Equations Calculator

Type one equation per line, for example 2x + y = 5 and x − y = 1. The calculator solves for each unknown, classifies the system (one solution, none or infinitely many), shows the matrix facts and draws the lines when there are two unknowns.

Runs entirely in your browser. Nothing you enter leaves your device.

How to use the systems of equations calculator

  1. Type one equation per line. Fractions and brackets work.
  2. Press Solve system.
  3. Read the solution and the type of system, then open the working.
  4. Use the Coefficient grid tab if you prefer to enter numbers into cells.

The method behind it

Elimination adds or subtracts equations to cancel one unknown. Substitution solves one equation for a variable and replaces it in the other. A system has exactly one solution when the coefficient matrix is invertible (non-zero determinant), none when the equations contradict, and infinitely many when one equation is a multiple of the other.

Worked example

Worked example: 2x + y = 5 and x − y = 1. Add the equations: 3x = 6, so x = 2. Then y = x − 1 = 1. Check: 2(2) + 1 = 5 ✓.

Frequently asked questions

How can I tell if there is no solution?

The lines are parallel: same slope but different intercepts. Elimination ends with a false statement such as 0 = 4.

What does infinite solutions mean?

The equations describe the same line (or plane). Every point on it is a solution.

Can it handle three variables?

Yes. Enter three equations in x, y and z.
