Matrix Calculator

Add, subtract, multiply, scale, transpose or raise a matrix to a power, with exact fractions. Other tabs row reduce and find rank, compute a determinant, find an inverse and show a 2×2 matrix as a transformation. Enter rows separated by semicolons, for example 1 2; 3 4.

Runs entirely in your browser. Nothing you enter leaves your device.

How to use the matrix calculator

  1. Choose a tab such as Operations, Determinant or Inverse.
  2. Type matrix A (and B if needed) with rows separated by semicolons.
  3. Press Calculate and read the result and the working.

The method behind it

Multiplication: entry (i, j) of AB is row i of A times column j of B, so A must have as many columns as B has rows. 2×2 determinant: det [[a, b], [c, d]] = ad − bc. 2×2 inverse: (1 ÷ det) · [[d, −b], [−c, a]], which exists only when det ≠ 0.

Worked example

Worked example: A = [[1, 2], [3, 4]]. det A = 1·4 − 2·3 = −2. The inverse is −1/2 · [[4, −2], [−3, 1]] = [[−2, 1], [3/2, −1/2]]. With B = [[5, 6], [7, 8]], AB = [[19, 22], [43, 50]].

Frequently asked questions

When does a matrix have no inverse?

When its determinant is zero. Such a matrix is called singular.

Is matrix multiplication commutative?

No. In general AB ≠ BA.

What is row reduction used for?

Solving systems of equations, finding rank and computing inverses.
