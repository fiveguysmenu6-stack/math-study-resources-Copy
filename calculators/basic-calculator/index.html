Basic Calculator

A simple calculator for everyday sums. It supports brackets, a percent key, memory keys (MC, MR, M+, M−), keyboard input and a list of your last calculations.

0

History

    Runs entirely in your browser. Nothing you enter leaves your device.

    How to use the basic calculator

    1. Press the keys or type on your keyboard. Enter or = gives the result.
    2. The % key turns the number before it into a percentage: 50% is 0.5, and 200*15% is 30.
    3. Use ⌫ to delete one character and AC to clear everything.
    4. M+ adds the current result to memory, M− subtracts it, MR recalls it and MC clears it.
    5. Tap a line in the history to bring that expression back.

    The method behind it

    The calculator evaluates the whole expression with the usual order of operations, so 2+3×4 is 14, not 20. Division by zero shows a clear error instead of a wrong number. Results are rounded to 12 significant digits to hide tiny floating-point noise such as 0.1 + 0.2 = 0.30000000000000004.

    Worked example

    Try: (12+8)/4 gives 5. 1200*7.5% gives 90. 1/8 gives 0.125.

    Frequently asked questions

    Why is 2+3×4 equal to 14?

    Multiplication is done before addition. If you want 20, type (2+3)*4.

    How does the % key work?

    It divides the number before it by 100, so 8% is 0.08. For percent-of, percent change and discounts use the percentage calculator.

    Is the history stored anywhere?

    Only in this browser's local storage, so it stays on your device. Clearing site data removes it.
