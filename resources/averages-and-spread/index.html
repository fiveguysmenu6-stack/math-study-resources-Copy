Mean, Median, Mode and Spread

Which average to use, and how to describe how spread out data is.

Guide · 7 min read · Updated 2026-11-14

On this page
  1. The three averages
  2. Which should you use?
  3. Range and quartiles
  4. Standard deviation
  5. Z-scores

The three averages

  • Mean: add all values and divide by how many there are.
  • Median: the middle value when the data is sorted (the average of the two middle values if the count is even).
  • Mode: the most frequent value.

For 3, 7, 7, 9, 10, 12, 12, 12, 40: the mean is 112 ÷ 9 ≈ 12.4, the median is 10 and the mode is 12.

Which should you use?

The mean uses every value, so it is pulled by outliers such as the 40 above. The median ignores how extreme the ends are, which makes it better for incomes or house prices. The mode is the only average that works for categories like favourite colour.

Range and quartiles

The range is largest minus smallest. Quartiles split sorted data into four parts: Q1, the median (Q2) and Q3. The interquartile range is Q3 − Q1, and a common outlier rule flags values beyond 1.5 × IQR from the quartiles.

Standard deviation

Standard deviation measures typical distance from the mean. For the population formula, find the mean, square each distance, average those squares (the variance), then take the square root. For a sample, divide by n − 1 instead of n. For 2, 4, 4, 4, 5, 5, 7, 9 the mean is 5, the squared distances add to 32, so population variance is 4 and σ = 2.

Z-scores

A z-score says how many standard deviations a value sits from the mean: z = (x − μ) ÷ σ. A value with z = 2 is two standard deviations above average.

Frequently asked questions

Can there be more than one mode?

Yes. A data set with two equally frequent values is bimodal.

Why divide by n − 1 for a sample?

It corrects the tendency of a sample to underestimate the true spread.

Is a large standard deviation bad?

Not by itself. It just means the data is spread out.
