The formulas most algebra courses reuse, in one place.

Exponents

aᵐ·aⁿ = aᵐ⁺ⁿaᵐ÷aⁿ = aᵐ⁻ⁿ(aᵐ)ⁿ = aᵐⁿ
a⁻ⁿ = 1/aⁿa⁰ = 1a^(1/n) = ⁿ√a

Special products and factoring

(a+b)² = a² + 2ab + b²(a−b)² = a² − 2ab + b²
a² − b² = (a−b)(a+b)a³ − b³ = (a−b)(a²+ab+b²)
a³ + b³ = (a+b)(a²−ab+b²)(x+p)(x+q) = x² + (p+q)x + pq

Quadratics

Formulax = (−b ± √(b²−4ac)) ÷ 2a
DiscriminantD = b² − 4ac
Vertexx = −b ÷ 2a
Sum and product of roots−b/a and c/a

Logarithms

log(xy) = log x + log ylog(x/y) = log x − log y
log(xⁿ) = n log xlog_b x = ln x ÷ ln b

Lines

Slopem = (y₂−y₁) ÷ (x₂−x₁)
Slope-intercepty = mx + b
Point-slopey − y₁ = m(x − x₁)
Perpendicular slope−1/m
